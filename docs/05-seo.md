# SEO notes

## Basics
- Ensure `robots.txt` exists at site root.
- Provide `sitemap.xml` and reference it in `robots.txt`.
- Use unique page titles and meta descriptions per major page.

## Recommended files in /public
- `robots.txt`
- `sitemap.xml`

## Page titles
- `index.php` should have a descriptive title about miniature license plate toys/premiums.
- `gallery.php` should include "Gallery" + main keywords.

## Future improvements
- Generate a sitemap that includes each set URL:
    - `/gallery.php?year=...`
- Add canonical tags if querystring variations become an issue.
