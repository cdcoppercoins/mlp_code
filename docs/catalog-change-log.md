# CopperCoins 3.0 – Catalog Change Log Policy

## Purpose
The Catalog Change Log exists to provide transparency and accountability for all material changes made to the CopperCoins Die System.  
It ensures that collectors can clearly see **what changed, when it changed, and why**.

The change log is an authoritative historical record and must never be silently altered or suppressed.

---

## What Qualifies as a Catalog Change

The following actions must always generate a catalog change event:

- Merging a mistaken die number into a canonical die
- Creating a tombstone die number
- Releasing a tombstone die number after the reservation period
- Reassigning a previously reserved die number to a new die
- Any administrative correction that changes how a die number resolves publicly

Cosmetic edits (grammar, formatting, image swaps) do not require change log entries unless they materially affect attribution interpretation.

---

## Required Change Log Data

Each catalog change event must record, at minimum:

- Event type (merge, release, reassignment, etc.)
- Affected die number(s)
- Canonical die number (if applicable)
- Effective date and time
- Admin user responsible for the action
- A human-readable reason for the change

Once recorded, a change log entry is immutable.

---

## Public Visibility Requirements

The Catalog Change Log must be:

- Accessible via a prominent link on the **home page**
- Accessible via a visible link on:
  - every tombstone die number page
  - every reassigned die number page

The log must support:
- chronological viewing
- reverse chronological viewing (most recent first)
- optional filtering by die number or date range

---

## PDF and Print Export

Collectors must be able to:
- download a PDF copy of the Catalog Change Log, and/or
- print a formatted version suitable for offline reference

The exported log must clearly display:
- CopperCoins branding
- generation date
- covered date range
- all included catalog change events

---

## Retention Policy

- Catalog change events must never be deleted.
- Historical accuracy takes precedence over convenience.
- Corrections to a change log entry, if ever required, must themselves be recorded as a new change event.

The Catalog Change Log is part of the permanent record of the CopperCoins Die System.
